## 🚀 项目

### 🌶️ [小辣椒 · 方言语音陪伴机器人](https://github.com/xuelinhuang49-prog/xiaolajiao)

面向农村留守老人的方言语音陪伴系统。**方言语音识别 + 本地大模型对话 + 主动照护引擎 + 家庭视频通话 + 跌倒守护**，让老人零学习成本、靠说话完成所有操作。

`Python` · `Ollama` · `语音识别` · `WebRTC` · `YOLOv8` · `SQLite`

### 🏘️ [数字乡村平台 · Village OS](https://github.com/xuelinhuang49-prog/village-os)

智慧乡村数字化管理 SaaS 平台，单仓库多模块，覆盖**乡村治理、农业种植、畜禽养殖、农产品电商、文旅民宿、养老、便民政务、政策补贴**等 20+ 业务模块，支持多租户、GIS 数字孪生、IoT 实时监控。

`Spring Boot 3` · `Vue3` · `MyBatis Plus` · `Redis` · `WebSocket` · `GIS`
